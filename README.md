# HOSPITAL-MANAGEMENT-SYSTEM
A secure Java Swing and MySQL-powered Hospital Management System featuring role-based authentication, book appointments, patient prescription management

Key Features
Role-Based Authentication (auth package): Secure login portal verifying active patient credentials and blocking deleted accounts.

Patient Self-Service Portal (patient package): Dedicated interface allowing patients to view their prescriptions.

Database Integration: Fully integrated with MySQL (hospital_db) for managing patient records, appointments, and prescriptions.
